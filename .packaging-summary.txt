🔧 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. BUILD PHASE (debian/rules)
   → Copies Python modules to /usr/lib/cuems-editor/
   → Copies static files
   → Prepares package for installation

2. INSTALL PHASE (debian/postinst)
   → Verifies /usr/lib/cuems/ venv exists (from cuems-utils)
   → Uses /usr/lib/cuems/bin/pip3 to install package into venv
   → Reloads systemd daemon

3. SERVICE MANAGEMENT
   → Service file provided by cuems-common package
   → Located at /lib/systemd/system/cuems-editor.service
   → Runs: /usr/lib/cuems/bin/python3 /usr/lib/cuems-editor/ws-server.py
   → Part of cuems-controller.target
